# 폰트 EULA 조항 조사

**폰트의 메트릭을 재는 것을 금지하는 조항이 실제로 있는가**

조사일 2026-09-24 · 장민석 (KISTI 과학기술연구망센터)

> 발표자 개인의 조사 결과이며 소속 기관의 공식 입장이 아닙니다.
> **법률 의견이 아닙니다.** 약관 문언과 폰트 파일을 원문으로 확인하고 분류한 기록이며, 변호사 검토를 대체하지 않습니다.

## 배경

KrIGF 2026 세션 [공익적 상호운용성을 위한 사전 법적 확신 메커니즘](https://msjang.github.io/krigf26-no-action-letter)(2026-07-02) 직후, 법률 패널로 참여한 박경신 교수(고려대 법학전문대학원·오픈넷)가 물었습니다.

> 실제로 EULA에 font metric 추출을 명시적으로 금지하는 조항이 있는가? 보통은 reverse engineering 금지조항만 있는 것으로 알고 있는데.

메트릭 호환 폰트(MCF) 제작이 저작권법상 문제되지 않고 계약법 문제만 남는다면, 그 계약 조항이 실제로 존재하는지 확인하면 회색지대의 상당 부분이 해소됩니다. 이 레포는 그 질문에 인상이 아니라 원문과 실측으로 답하려는 기록입니다.

## 조사한 것

| | 대상 | 규모 |
|---|---|---|
| 1 | 제품 EULA·권리자 약관 문언 | **7종** |
| 2 | 폰트 파일 내장 라이선스 전수 | **1,862종** (macOS·MS Office·한컴오피스) |
| 3 | 실제 공문서의 폰트 사용 실태 | **450건** (정책브리핑 보도자료 HWPX) |
| 4 | 해외 MCF 선례 메트릭 실측 | **7쌍** (Carlito·Caladea·Liberation) |
| 5 | 한컴 고유 포맷(HFT) 폰트 레지스트리 | **387종** |
| 6 | 공문서 서식 글꼴을 지정하는 법령 | 시행규칙 **별표 4·5** |

## 결과 요약

### 1. 메트릭 추출을 금지하는 조항 — 0건

약관 7종, 폰트 파일 1,862종 어디에도 advance width·kerning·line gap 등을 **측정하거나 추출하는 행위**를 금지하는 문언이 없었습니다.

### 2. 역설계 금지 조항도 일반적이지 않습니다

- **폰트 파일 내장 라이선스 860건(고유 49종) 중 역설계 금지 문구: 0건**
- 약관 7종 중 역설계 금지 조항을 둔 곳: **(주)한양정보통신 1곳**
- **한컴오피스 제품 EULA 12개 조 전문에 역설계·디컴파일·분해 계열 문언이 하나도 없습니다**

| 문서 | A 메트릭추출 | B 역설계 | C 수정·개작 | D 사용범위 | E 복제·배포 |
|---|:-:|:-:|:-:|:-:|:-:|
| 한컴오피스 한/글 for Mac 12.30.0 제품 EULA | X | **X** | X | O | O |
| 한컴오피스 2020 / 2022 "사용권" 도움말 | X | **X** | △ | O | O |
| (주)한양정보통신 EULA (2013-10-10 시행) | **△** | **O** | O | O | O |
| 윤디자인 FONCO "사용범위" | X | X | X | O | △ |
| 윤디자인 FONCO "이용약관" | X | X | X | X | X |
| Monotype 내장 라이선스 문구 | X | **X** | X | △ | O |
| Microsoft 내장 라이선스 문구 | X | **X** | X | O | X |

`O` 있음 · `X` 없음 · `△` 문언상 다툼의 여지 → [조항별 원문 발췌](clause-matrix.md)

메트릭에 가장 근접한 문언은 한양정보통신 EULA 2-2)-① 하나였습니다.

> 저작권자의 사전 서면 승인 없이는 본 소프트웨어 대해서 웨이트(weights)의 추가 제작, **폰트간격 및 자간 수정**, 소스 코드 수정, 개작, **역 설계**, 다른 디지털포맷으로 변형, 복사, 대여, 임대, 재판매, 배포, 이전을 할 수 없습니다.

열거된 9개 행위의 공통 목적어는 "본 소프트웨어", 즉 사용권을 받은 폰트 파일 자체이고, "폰트간격 및 자간"에 붙은 동사는 **수정**입니다. 측정·판독을 가리키는 문언은 없습니다.

### 3. 폰트 파일 안에서 "수정"은 금지가 아니라 허용으로만 등장합니다

1,862종 중 "modify" 계열 단어가 나오는 문구는 4종뿐이고, 전부 권리를 **부여**하는 맥락이었습니다 — ParaType(명시적 허용), STIX/OFL(개명 조건부 허용), Microsoft 첨부 MIT 라이선스.

→ [전수 조사 상세](findings-licenses.md)

### 4. 공문서 450건 중 413건(91.8%)이 이미 폰트가 대체된 채 저장되어 있습니다

HWPX는 `substFont` 항목에 **문서가 요청했으나 없어서 대체된 폰트**를 기록합니다. 문서가 스스로 남긴 레이아웃 훼손의 증거입니다.

| 요즘 공문서가 쓰는 폰트 | 등장률 | | 대체된 폰트 | 등장률 |
|---|---:|---|---|---:|
| 함초롬바탕 | 98% | | 신명조■얒a | 63% |
| 휴먼명조 | 97% | | -윤고딕130 | 61% |
| 함초롬돋움 | 96% | | HY각헤드라인M | 61% |
| 돋움체 · 바탕 · 맑은 고딕 | 95·93·92% | | -윤고딕220 | 60% |
| HY헤드라인M · 한양신명조 | 85·78% | | 휴먼명조 | 43% |

대체는 오픈소스 도구가 아니라 **한컴오피스 안에서** 일어났습니다. 이것은 장래의 우려가 아니라 이미 벌어진 일입니다.

→ [공문서 실태 상세](findings-gov-docs.md)

### 5. MCF는 "수치는 같고 표현은 다르다"가 실제로 성립합니다

| 원본 → MCF | advance width | 글리프 윤곽선 | 문단 폭 |
|---|:-:|:-:|:-:|
| Calibri → Carlito | 92/92 (100%) | 13/13 **상이** | **100.00%** |
| Arial → Liberation Sans | 92/92 (100%) | 15/15 **상이** | **100.00%** |
| Times New Roman → Liberation Serif | 92/92 (100%) | 15/15 **상이** | **100.00%** |
| Courier New → Liberation Mono | 92/92 (100%) | 15/15 **상이** | **100.00%** |
| Cambria → Caladea | 36/92 (39%) | 15/15 상이 | 94.89% |

7쌍 전부에서 **윤곽선 제어점 좌표가 일치하는 문자가 하나도 없었고**, 그럼에도 6쌍에서 문단 폭 차이가 **0.0**이었습니다.

### 6. 한컴오피스 2026년판에 1990년대 폰트 387종이 그대로 들어 있습니다

HFT는 **"Han Unified Font File"** — 한컴 고유 포맷입니다. TrueType이 아니라 name 테이블이 없고, 대신 헤더에 평문 저작권과 빌드일자가 있습니다.

- 빌드일자 범위 **1993-11-24 ~ 1999-04-16**
- 저작권 표시: **한글과컴퓨터 286종(74%)**, 한양시스템즈 27, 양재 20, 한미디어 6, 표시 없음 48
- 공문서의 한글 폰트 참조 7,176건 중 **1,434건(20%)이 HFT**
- 공문서 98%에 등장하는 `명조`·`한양신명조`, 97%의 `HCI Poppy`가 전부 이 포맷

**HFT의 4분의 3이 한컴 자신의 저작물로 표시되어 있습니다.** 제3자 협의 없이 한컴이 단독으로 결정할 수 있는 범위입니다.

→ [HFT 레지스트리 상세](findings-hft.md)

### 7. 국가가 부령으로 사기업 폰트를 서식 표준 글꼴로 지정해 두었습니다

시행규칙 **조문 본문**에는 글꼴 지정이 없습니다(전문 87,500자, 글꼴·서체·폰트 0건). 그런데 **별표**에 있습니다.

> 서식 명칭의 글꼴은 **견고딕**으로 하고 그 외의 글자는 **돋움체**로 하되, 필요한 경우 다른 글꼴을 사용할 수 있다.
> — 「행정업무의 운영 및 혁신에 관한 규정 시행규칙」 [별표 4] 제7호 나목

| 부령 지정 글꼴 | 저작권 표시 | 내장 라이선스 | 공문서 등장 |
|---|---|---|---:|
| **돋움체** (별표 4) | HanYang I&C — 한양정보통신 | 없음 | 95% |
| **맑은고딕** (별표 5, 큰글자 서식) | Microsoft | **"Any other use is prohibited"** | 92% |
| **견고딕** (별표 4·5) | **특정되지 않음** — HY·한양·한컴·신명 혼재 | — | 4% / 2% |

개입 지점이 법률이 아니라 **행정안전부령의 별표**입니다. 국회 입법 없이 부령 개정으로 가능한 사안이고, 다만 지정을 바꾸려면 레이아웃을 보존할 대체 폰트가 먼저 있어야 합니다 — **부령 개정과 MCF는 대체재가 아니라 선후 관계**입니다.

→ [법령 조사 상세](findings-regulation.md)

### 8. 100개 대 1,600만 개

| 함초롬바탕 | 개수 |
|---|---:|
| **윤곽선 제어점 좌표값** — 대법원 99다23246이 보호 대상으로 특정한 표현 | **16,461,442** |
| **MCF가 일치시키는 배치 수치** — 한글 폭 1 + 라틴 약 92 + 수직 메트릭 8 | **약 100** |

한글 음절 1,596자 표본에서 **고유 advance width는 단 1개**였습니다. 한글 부분의 메트릭 호환은 사실상 숫자 하나를 맞추는 문제입니다. 함초롬 계열만 0.97 em이고 나머지가 1.00 em이라는 점이 공문서가 깨지는 구체적 기전입니다.

→ [메트릭 실측 상세](findings-metrics.md)

## 조사 과정에서 확인된 구조

### 제한은 원권리자 층에 있고, 그 층은 분산되어 있습니다

한컴오피스 제품 EULA에서 글꼴을 다루는 유일한 조항(제7조)은 금지가 아니라 안내입니다.

> 제품에 포함된 글꼴 및 클립아트 중 일부는 (주)한컴과 글꼴 및 클립아트의 저작권자와의 계약에 따라 본 제품 사용 시에만 사용하도록 제한되어 있습니다. 따라서 본 제품 외에서 해당 글꼴 및 클립아트를 사용 시, 사전에 저작권이 있는 해당 저작사 또는 저작권자에게 사용권 문의를 하시기 바랍니다.

그런데 한컴 도움말이 밝힌 번들 글꼴의 권리자는 **16개 주체**입니다 — (주)한컴, 휴먼컴퓨터, (주)한양정보통신, 신명시스템즈, 한국컴퓨그래피, 태시스템서체, 양재미디어(주), 안상수, 한재준, 빗스트림, 한미디어, (주)모리스디자인, (주)샘틀로미디어, 서울시스템(솔트웍스), (주)윤디자인연구소, 중소기업중앙회.

다만 공문서 실측 결과 병목은 **20종 남짓**이고 권리자는 5곳 안팎으로 수렴합니다. 전면 협의가 필요한 규모가 아닙니다.

### 계약이 법정 허용을 배제할 수 있는지가 미정입니다

EU 소프트웨어 지침 2009/24/EC 제8조 제2문:

> Any contractual provisions contrary to Article 6 or to the exceptions provided for in Article 5(2) and (3) shall be null and void.

호환 목적 디컴파일을 허용한 제6조에 반하는 계약 조항은 무효라는 규정입니다. **우리 저작권법 제101조의3·제101조의4·제101조의5 어디에도 대응 규정이 없습니다.**

조사 결과를 종합하면 "회색지대"의 실체는 금지 조항의 존재가 아니라 **금지도 허용도 사전에 확정할 수 없는 상태** 자체입니다.

## 재현

```bash
pip install fonttools

# 폰트 내장 라이선스 전수 추출
python3 tools/dump_font_licenses.py "macOS=/System/Library/Fonts" ... > census.json

# 공문서 폰트 수집 (korea.kr robots.txt Allow 확인 후, 요청 간 지연)
python3 tools/harvest_gov_doc_fonts.py --pages 60 --max-docs 450 --out gov.json

python3 tools/metric_compat.py <원본.ttf> <MCF.ttf>

python3 tools/dump_hft_registry.py > hft-registry.json
```

## 조사가 하지 않은 것

- MCF 제작이 적법하다는 결론을 내리지 않았습니다. 조사한 약관에 해당 금지 조항이 **없다는 사실**을 확인했을 뿐입니다.
- 특정 기업·기관의 정책을 평가하지 않았습니다. 확인된 문언과 수치만 기술했습니다.
- 약관 원문은 전문 전재 대신 조항 분석에 필요한 범위에서 발췌 인용하고, 출처 URL·수집일·수집 방법을 함께 적었습니다.
- 원본 폰트를 개변하지 않았습니다. 규격이 정한 위치의 값을 읽어 대조했을 뿐입니다.
